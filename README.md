# Open64x0 Core.

## Brief:

Here you will find samples, documentation and the VHDL sources.
The ROM needs the 64asm from NeKernel's `necti`, please get that as well.

## Cloning: 

```sh
git clone git@github.com:nekernel-org/open64x0.git
```
